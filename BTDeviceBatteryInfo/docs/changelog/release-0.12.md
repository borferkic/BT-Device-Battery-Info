# BT Device Battery Info 0.12

## What's new

- Faster startup: the widget appears sooner and discovers devices progressively.
- A cleaner view: disconnected devices are grouped under `Disconected Devices` and can be expanded when needed.
- A new `About` window with app information and Instagram, Twitch, and LinkedIn links.
- Improved device-state updates and battery readings when Windows provides the data.
- Greater stability during startup and Bluetooth updates.
