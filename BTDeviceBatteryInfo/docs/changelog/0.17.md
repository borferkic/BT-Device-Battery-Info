# Version 0.17 — Options and Elegant Black theme

**Date:** 2026-09-23

**Application version:** 0.17

## Summary

This release adds `Options`, the `System` and `Elegant Black` themes, and access to `About` and its support links. It also unifies device icons and updates the dark theme.

## Added

- Added settings for Windows startup and the taskbar widget in `Options`.
- Added a theme selector with live preview and persistence on save.
- Added PayPal and Patreon links to `About`.
- Embedded Geist Sans for `Elegant Black` and included its OFL license.

## Changed

- Replaced device and primary toolbar glyphs with Lucide vector icons.
- Updated `Elegant Black` with a shadcn/ui-inspired appearance and pill-shaped buttons; `System` retains the previous theme and system font.
- Moved the `About` action lower in the taller `Options` window, keeping its action buttons in the footer.

## Fixed

- Fixed a startup crash when applying a theme during initialization.
- Removed the duplicate taskbar widget control from the main toolbar; it remains available in `Options` and the system tray.

## Validation

- Release publish completed for self-contained, single-file `win-x64`; WPF XAML compiled successfully.
- No automated tests were discovered. Hardware validation for P-014 remains open in `docs/pending.md`.
