# Version 0.11 — Application Icon

## Summary

Version 0.11 adds the BT Device Battery Info application icon across the Windows experience.

## Added

- Created `Icon.ico` from the supplied `Icon.png` source image.
- Included icon resolutions for 16, 32, 48, 64, 128, and 256 pixels.
- Applied the icon to the Windows executable.
- Applied the icon to the widget window.
- Replaced the generic system-tray icon with the BT Device Battery Info icon.

## Validation

- Built successfully in Release configuration with zero errors and zero warnings.
- Confirmed that Windows extracts the Bluetooth icon from the generated executable.

## Version information

- Product version: `0.11`
- File version: `0.11.0.0`
