# Versión 0.15 — Recuperación de batería HFP/PnP

## Resumen

La versión 0.15 recupera la lectura de batería de auriculares Bluetooth Classic cuando Windows la publica mediante HFP/PnP. La detección usa el dispositivo físico agrupado por `ContainerId`; no depende de rutas, nombres ni direcciones específicas de fabricante.

## Corregido

- Se corrigió la comparación de `DEVPROP_TYPE_GUID` durante la consulta PnP de `ContainerId`.
- Se enumeran devnodes Bluetooth registrados para localizar la propiedad de batería HFP de Windows mediante `BthHFEnum`.
- Al no quedar ningún endpoint conectado, se elimina el porcentaje guardado y la interfaz muestra `Battery unavailable`.
- Los logs locales se escriben en inglés e indican la fuente de la lectura (`PnP HFP native`, PnP o GATT) sin guardar identificadores Bluetooth.

## Validación

- Compilación Release con cero advertencias y errores.
- Seis escenarios del coordinador de consultas de batería aprobados.
- Validación manual confirmada con auriculares HFP conectados y tras desconectar el dispositivo.
